## 4. What these numbers say

**The spread is over IMAGES, not over seeds.** Each cell here is a single training run, so `2×SE` answers *"does this model attend differently on these images?"* — NOT *"would another training seed reproduce this?"* No claim of seed-stability is made or supported by this table. (TASK-06B/08 deltas, which do carry seed replication, are a different and stronger kind of number.)

- **vit_base / saga**: in-box mass 0.4401 vs a uniform-attention null of 0.4558 — at or below the null; Δ vs baseline +0.0260 (not significant at 2×SE).
- **vit_small / saga**: in-box mass 0.4438 vs a uniform-attention null of 0.4558 — at or below the null; Δ vs baseline -0.0070 (not significant at 2×SE).
- **vit_small / registers**: in-box mass 0.5495 vs a uniform-attention null of 0.4558 — above the null; Δ vs baseline +0.0988 (significant at 2×SE).

Significant deltas at 2×SE, all of them:

- `vit_small` / registers / `inbox_mass` (boxes20): +0.0988 ± 0.0290 — above baseline
- `vit_small` / registers / `pointing_hit` (boxes20): +0.3000 ± 0.1051 — above baseline
- `vit_small` / registers / `attn_entropy_bits` (random200): +0.7272 ± 0.0524 — above baseline
- `vit_small` / registers / `ring1_mass` (random200): -0.1465 ± 0.0092 — below baseline
- `vit_small` / saga / `ring1_mass` (random200): -0.0189 ± 0.0067 — below baseline

> **This does not support the framing TASK 11 was written around.** The task assumed the teaser would show SAGA's gate suppressing the sink address. On this probe set the model that measurably localizes is **registers**, not SAGA: it carries 4 of the 5 significant deltas, including the in-box mass and the pointing game, while SAGA's only significant effect is a small reduction in ring-1 mass. The figure and this note report that as it stands; the framing is the human's call, not something to be resolved by choosing different panels.

## 5. Caveats that bound every number above

1. **The registers run is not seed-matched to the others.** `legacy_vits_registers` is a LEGACY e2-era checkpoint (manifest seed `rlast`, no seed control), while the baseline and SAGA runs are the clean seeded e2r reruns. Per the recipe erratum it belongs to the same (vit_small, mixup) cell, so the comparison is legitimate — but it is a different training era, not a paired seed.
2. **`inbox_mass` has little headroom.** The GT boxes cover 45.6% of the cropped frame on average (std 0.3753), so uniform attention already scores 0.4558. A model has to beat that to mean anything, and `boxes20` is only n=20.
3. **Probe-set scale.** `random200` is 200 images (one per class over 200 seeded classes); `boxes20` is 20 COCO-val images. Both are frozen forever, so these numbers are reproducible, but they are a probe, not a benchmark.
4. **Attention is not attribution.** CLS→patch attention in the last block is one readout of where a model looks; it is not a saliency method and carries none of their guarantees.
