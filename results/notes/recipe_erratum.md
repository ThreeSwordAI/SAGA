## Finding

Every legacy e2 run trained WITH MixUp+CutMix, including all runs in `*_nomix` directories. **Cell identity comes from the RESOLVED training config, never from a directory name.** New column `recipe_actual` everywhere; the old `recipe` column is a directory name (`recipe_dirname`).

## Mechanical proof

1. The legacy resolver (`load_config` in `classification/tools/train.py` at commit `31f4bac`, executed verbatim by this script) merges only `_base_` plus the matched variant entry (`id/name/model`). The top-level `augmentation:` block of `variants_nomix.yaml` — the only place mixing was disabled — was therefore never merged. `base_nomix.yaml` is referenced by no legacy code path.
2. Resolved-config diff, legacy nomix launch vs legacy mixup launch (ViT-S id 0), recomputed now: **ZERO differing keys**.
   The resolved legacy "nomix" augmentation block: mixup_alpha=0.8, cutmix_alpha=1.0, rand_aug=True (m9/n2), random_erase_prob=0.25.
3. Ground truth from the cluster (checked by the human, 2026-09-04): the resolved config the legacy trainer itself dumped, `$OUT_ROOT/e2/checkpoints/ViT-S_baseline_nomix/config.yaml`, shows `mixup_alpha: 0.8, cutmix_alpha: 1.0`. The Part-2 provenance harvest commits all 12 dumped configs to `results/legacy/resolved_configs/`.
